# ZotAgent 0.5.0 — OpenCode 兼容、全文工具与界面适配

状态：用户已授权将本轮全部修改统一提交 GitHub。以下记录实现、验证结果和真实 Windows Zotero 复验边界；Git 提交不等同于发布 Release 附件。

## 本次修改

1. 去掉 OpenCode `run --dir`，通过进程 cwd 保持工作目录；WSL 和登录 Shell 启动后重新固定目录。Codex 去掉冗余 `--cd`；Claude 仅图片输入使用 `--input-format stream-json`，去掉文本默认格式和已内嵌图片的目录授权。保留结构化输出、恢复列表、会话 ID、模型及图片必需参数。
2. 当前主文献＋已导入参考文献支持“全选全文”和“取消全选”，只改变选择，不发送。
3. “导出 PDF 文本”列出文献，默认全选，可取消部分；选择文件夹后每篇单独导出 Markdown。含文献元数据和 PDF 提取文本，不调用 Agent、不做 AI 整理。同名自动编号，不覆盖；逐篇失败报告，不生成空文件。主文献优先已绑定的阅读 PDF，参考文献优先 Zotero 首选 PDF。
4. Runtime 设置页增加启动、停止、重启。显示端口、PID；鉴权和实例 ID 确认后才停止。有任务或原生终端时显示清单并确认，手动停止后不因提问或检测重新拉起。插件退出时请求停止自身启动且可认证的 Runtime。
5. 结构化输入框 Enter 发送、Shift+Enter 换行，忽略输入法确认及重复按键。原生终端保留 CLI 按键行为。
6. OpenCode 下拉菜单展示实际安装环境的真实模型 ID，连接、打开菜单和环境切换时读取；手动刷新额外更新 CLI 模型缓存。失败保留原选择，模型消失时标记；不接受显示名称手动输入。
7. 空模型设置现在表示“跟随同一环境最近使用的模型”：每次发送前读取 `opencode debug paths` 提供的 state 目录中的 `model.json`，并显式传入模型 ID。不存在、不可读或已下架时提示选择，不回退旧默认配置；聊天同步显示解析后的模型。
8. Agent 测试保留手动路径，无效路径报错；仅路径空值时自动查找回填。Windows 的手动 Node/Runtime 路径也受保护，内置版本化 Runtime 仍可升级。

## 请在 Windows Zotero 验收

1. 安装上述新 XPI 并重启 Zotero；外置 Runtime 请同步当前源码。协议 5 旧服务没有停止接口，需从其原启动终端退出一次；插件不会按端口杀掉它。新版本要求 Runtime 协议 6。
2. 设置页测试已填写的 Agent 路径，确认路径不被覆盖；填无效路径应提示错误。清空路径后点击检测应填入检测结果。
3. OpenCode 选“跟随最近使用的模型”发送问题；再从菜单选择 `opencode/space-bunny-free` 等实际可用 ID 重试。切换 Windows/WSL 后核对列表属于所选环境。
4. 导入多篇参考文献，点击全部附加/取消，确认主文献和参考文献勾选一致；确认只改变选择、不发送。
5. 导出两篇 PDF 到自选文件夹，确认独立 Markdown、元数据和全文；重复导出不覆盖旧文件，扫描件/无 PDF 条目应单独提示。
6. 输入框 Enter 发送、Shift+Enter 换行；中文输入法确认候选词不发送。
7. 测试 Runtime 停止、停止后提问、启动和重启；有任务时停止应列出任务并确认，取消停止应保留任务。
8. 简单复验 Codex/Claude 聊天、图片、原生历史恢复和笔记归档。

## 限制

最近使用记录不是多个已打开 OpenCode 终端的实时焦点状态。列表中存在模型也不保证远端可用、登录或额度正常。PDF 导出为提取文本，不包含 OCR、AI 整理或版式重建。已失去 Token/身份信息的服务不会被停止。

## 内容尺寸适配

文献、消息、面板及窗口尺寸变化时按内容调整对话框，不缩小字体。多文献适度增宽，标题换行，取消参考文献列表的固定 92px 高度限制；内容超出视口时滚动。保留手动调整尺寸，最小化状态不自动展开，关闭后清理观察器。新增几何测试覆盖增高、边界和最小化保护；真实 Zotero 视觉效果待验收。

## 手动缩放震荡修复

移除子元素 ResizeObserver 到自动尺寸调整的反馈循环；消息区使用固定预留高度，避免把已分配高度误当作内容需求。指针按下期间暂停适配，松手后如尺寸改变则保留用户尺寸，后续内容通过内部滚动展示。自动模式只按需扩展，不反复收缩；仍限制在视口内。新增回归覆盖拖拽暂停、手动尺寸优先及多次适配稳定性。

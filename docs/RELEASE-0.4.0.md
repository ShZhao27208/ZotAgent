## 已纳入代码

- 同一主文献的多个窗口、三个 Agent 共享原生归档笔记；新建笔记后，已提交任务仍绑定旧目标。
- 完成、失败和中断时归档问题、完整可见回答、时间、文献来源、截图及全文数量；不保存思考和 PDF 全文，不额外调用模型。

- 全部 Agent 不主动截断提取文本；保留 4 MiB 请求体限制及准确提交状态。
- 前端取消、历史文献恢复、批次失败判断、Claude 图片输入、多文本块和临时图片清理的修改。

## 使用入口

结构化聊天窗口新增当前记忆笔记及新建、打开、导出、重试操作；无主文献时提示不自动归档。命名和排序位于 Zotero 设置 → ZotAgent。手动保存子笔记继续作为精选回答入口，允许与历史重复。原生终端不参与自动归档。

推送成功后，实际 SHA、提交时间、推送完成时间、目标分支、产物校验值写入本地 `VERSION-HISTORY.md`；不预填成功信息。
